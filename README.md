# Cumpleaños de Vanesa Canul

Sitio estático para GitHub Pages. El archivo `index.html` contiene la página y el audio integrado.

## Publicación
1. Sube `index.html` a la raíz de tu repositorio.
2. En Settings → Pages, selecciona Deploy from a branch.
3. Elige `main` y `/ (root)` y guarda.

## Importante sobre el audio
El HTML incluye un archivo MP3 comercial proporcionado para esta felicitación. Mantén este paquete para uso privado o asegúrate de contar con los derechos/licencia necesarios antes de publicarlo en un repositorio público o distribuirlo. GitHub puede retirar contenido que infrinja derechos de autor.

La reproducción automática con sonido puede ser bloqueada por el navegador; si ocurre, el visitante deberá tocar o hacer clic en la página.
